## Core (pure / headless) — T1–T5

### T1 — `Todo.completed_at` field
- **Test** (`tests/test_models*` / `tests/test_stores.py`): `to_dict`/`from_dict` round-trip of `completed_at` (ISO); legacy dict without the key → `None`; garbage value → `None` (via `_parse_iso`).
- **Impl:** add `completed_at: Optional[datetime] = None` to `Todo` (`models.py:105-133`), declared like `due`; serialize via `_iso` (`to_dict`) / `_parse_iso` (`from_dict`). NOT the tolerant-coercion class (`_clean_*`) — it's a plain datetime.
- **Commit:** `feat(models): Todo.completed_at (nullable, ISO round-trip)`

### T2 — `completed_at` lifecycle in `TodoStore`
- **Test** (`tests/test_stores.py`): `complete()` sets `completed_at == updated`; `reopen()`/`restore()` clears it to `None`; a recurrence clone from `complete()` spawns `completed_at=None`.
- **Impl:** `complete()` (`todo_store.py:112-126`) `t.completed_at = t.updated` (alongside the existing `reminders.silence(t)`); `reopen()` (`:128-137`) `t.completed_at = None`; confirm `_spawn_recurrence` (`:182-204`) does NOT copy it (already omits `ics_uid`/`linked_note_ids`).
- **Commit:** `feat(store): stamp completed_at at done-grace, clear on reopen`

### T3 — `core/diary.py`: `DiaryLine` + `DiaryStore`  **[P1-1]**
- **Test** (`tests/test_diary.py` new, `tmp_path`, no Qt): round-trip; add/edit/delete; **edit never re-stamps `ts`/`state_tag`/`context`**; corrupt JSON → `.corrupt-<ts>` backup + `[]`; non-dict row skipped; **bad/missing-`ts` row dropped on reload (never loaded as `ts=None`) [P1-1]**; `save()` atomic.
- **Impl:** `DiaryLine{id,ts,text,state_tag,context}` dataclass (uuid4 hex id) + `to_dict`/`from_dict` (`_iso`/`_parse_iso`). `DiaryStore(vault_dir)` mirroring `TodoStore` (`reload`/`save`/`_backup_corrupt`/`all`/`get`/`add`/`edit`/`delete`); `reload` drops rows whose parsed `ts is None` (mirror `activity_store.py:75-77`).
- **Commit:** `feat(diary): DiaryStore + DiaryLine — tolerant store, poison-ts skip`

### T4 — Skeleton builder `build_diary_week` (pure)  **[P2-2]**
- **Test** (`tests/test_diary.py`): item lands in covering span `[start,end)`; open span uses `end=now`; item outside all spans → `untracked`; Monday-start week; items at 23:59:59 / 00:00:00; empty week; cross-week lines excluded; **cross-midnight span split — a todo completed 00:30 lands in a clipped span on the later day, not `untracked` [P2-2]**.

- **Commit:** `feat(diary): build_diary_week skeleton — span weave + cross-midnight split`

### T5 — Parser `diary` intent + verbatim remainder  **[P2-3]**
