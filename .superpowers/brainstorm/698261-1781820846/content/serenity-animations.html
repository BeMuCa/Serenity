Dev notes — PySide6 implementation map

How each demo behaviour maps to a real Qt approach when building Serenity in the desktop app.

StateVisual herePySide6 approach
IDLEvertical breathing bob, periodic eye blink QPropertyAnimation on a pos/y offset (loop, easing InOutSine); blink = a QTimer swapping to an "eyes-closed" sprite frame for ~120 ms.
TYPINGhead tilts down, "…" bubble, micro-shake Frame-stepping QTimer over a sprite sheet (QPixmap sub-rects); shake via tiny random QPropertyAnimation on pos. Bubble = child QLabel with QGraphicsOpacityEffect.
THINKINGhead tilt, thought dot rising Static tilt = QGraphicsRotation / QTransform.rotate() on the QLabel pixmap; rising dots = looping QPropertyAnimation on small overlay widgets' pos + opacity.
CHEERhappy bounce + sparkle particles Bounce = QPropertyAnimation on y with OutBounce easing; sparkles = a pool of QLabels animated by a QParallelAnimationGroup, or paint them in paintEvent driven by a QTimer particle list.
REMINDalert lean + pulsing ring Lean = one-shot QPropertyAnimation rotate; ring = custom paintEvent drawing an expanding drawEllipse whose radius/alpha advance on a QTimer (loop).
APPEARslides in from right screen edge QPropertyAnimation on the dock widget geometry/pos (OutCubic), paired with QGraphicsOpacityEffect fade. Reverse the same animation for HIDE.
Pixelationdownscale → nearest-neighbor upscale Render base QImage small, then scaled(w,h, Qt.IgnoreAspectRatio, Qt.FastTransformation) back up (Fast = nearest-neighbor). Cache per state to avoid per-frame cost.
Category formper-category tint, prop & expression Tint via QGraphicsColorizeEffect (set color+strength) or a CompositionMode_Multiply overlay; prop = an extra QLabel/sprite layer toggled per category. Drive from the active time-tracking category enum.

Core loop one master QTimer (~33 ms) advances the active state machine and repaints; state enum decides which sprite frames / effects are live.
